# Работа с дебаггером GDB

## Введение

GDB — это инструмент для отладки программ на C. Он позволяет поставить программу на паузу, посмотреть значения её переменных и продолжить выполнение по шагам.

С помощью GDB можно понять, в каком месте программа начинает работать неправильно. Для управления отладчиком используются команды.

## Подготовка программы

Создадим файл `main.c` с неправильной логикой:

```c
#include <stdio.h>

int add(int a, int b)
{
    int result = a - b;
    return result;
}

int main(void)
{
    int x = 7;
    int y = 3;
    int answer = add(x, y);
    printf("%d\n", answer);
    return 0;
}
```

Программа должна складывать числа, а она вычитает. Ожидаемый результат 10, фактический 4.

Соберём файл, отключив оптимизации:

```sh
gcc -g -O0 -Wall -Wextra main.c -o app
```

Значения параметров:

- `-g` - добавляет отладочную информацию. Она позволяет GDB показывать строки исходного кода и имена переменных.
- `-O0` - отключает большинство оптимизаций, чтобы было удобнее выполнять программу по шагам.
- `-Wall -Wextra` - включает дополнительные предупреждения компилятора.

Откроем программу в GDB:

```sh
gdb ./app
```

## Запуск и остановка

Команда `start` запускает программу и останавливает её в начале функции `main`:

```sh
(gdb) start
```

Важно: показанная строка обычно ещё не выполнена. Поэтому переменная `x` пока не получила значение `7`.

Команда `run`, или `r`, запускает программу с начала:

```sh
(gdb) run
```

Если точки останова не заданы, программа обычно выполнится до конца или до возникновения ошибки.

Команда `continue`, или `c`, продолжает выполнение с текущего места:

```sh
(gdb) continue
```

Программа будет работать до следующей точки останова, другой причины остановки или завершения.

Если программа зависла, её выполнение можно прервать сочетанием `Ctrl+C`. После этого можно посмотреть текущую строку и значения переменных.

Для выхода из GDB используется:

```sh
(gdb) quit
```

Сокращение - `q`.

## Выполнение по шагам

### Команда next

`next`, или `n`, выполняет текущую строку и переходит к следующей. Если в строке вызывается функция, она выполняется целиком.

```sh
(gdb) next
```

Состояние будет примерно таким:

```sh
  int x = 7;             x = 7
->int y = 3;             следующая строка
```

Ещё один шаг:

```sh
(gdb) next
```

```sh
  int x = 7;             x = 7
  int y = 3;             y = 3
->int answer = add(x, y);
```

Стрелкой обозначена строка, которая будет выполнена следующей.
### Команда step

`step`, или `s`, позволяет зайти внутрь вызываемой функции.

На строке:

```c
int answer = add(x, y);
```

step перейдёт внутрь add:

```c
int add(int a, int b)
{
    int result = a - b;
    return result;
}
```

Разница между командами:
* next  выполняет шаг без захода в функцию
* step  выполнгяет шаг с заходом в функцию
### Команда finish

`finish` продолжает выполнение до возврата из текущей функции:

Например, из add мы вернёмся в main. GDB обычно также покажет возвращённое значение.
### Команда until

Команда `until` позволяет продолжить выполнение до указанной строки в текущем вызове функции:

```sh
(gdb) until 14
```

Выполнение также остановится, если текущая функция завершится раньше.

## Просмотр переменных

Для просмотра значения используется `print`, или `p`:

```sh
(gdb) print x
$1 = 7

(gdb) print y
$2 = 3
```

Можно вывести результат выражения:

```sh
(gdb) print x + y
$3 = 10
```
Внутри add можно выполнить:

```sh
(gdb) print a
(gdb) print b
```
### Просмотр нескольких значений

Команда `info args` показывает параметры текущей функции:

```sh
(gdb) info args
a = 7
b = 3
```

Команда `info locals` показывает локальные переменные:

```sh
(gdb) info locals
result = 4
```

Команда `ptype` показывает тип:

```sh
(gdb) ptype result
type = int
```
### Автоматический вывод

Команда `display` выводит выражение при каждой остановке, когда оно доступно:

```sh
(gdb) display result
```

Убрать автоматический вывод с номером 1:

```sh
(gdb) undisplay 1
```

## Точки останова

Точка останова — это место, где программа должна приостановить выполнение.

Остановка в функции:

```sh
(gdb) break add
(gdb) run
```

Остановка на конкретной строке:

```sh
(gdb) break main.c:13
```

Можно поставить условную точку:

```sh
(gdb) break main.c:13 if x == 7
```

Программа остановится в этом месте, только если условие истинно.

Команда `tbreak` создаёт одноразовую точку останова:

```sh
(gdb) tbreak add
```

После срабатывания она удаляется.

Управление точками:
* `info breakpoints` - список точек
* `disable` - отключить точку
* `enable` - включить точку
* `delete` - удалить  точку
Команда `break` задаёт место остановки. Для запуска или продолжения программы нужны `run` или `continue`.

## Стек вызовов

Стек вызовов показывает, какие функции привели программу в текущее место.

Команда:

```sh
(gdb) bt
```

Внутри `add` результат будет:

```sh
#0 add(a=7, b=3)
#1 main()
```

`#0` — текущий вызов. `#1` — вызвавшая его функция.

Чтобы посмотреть переменные из `main`, выберем её кадр:

```sh
(gdb) frame 1
(gdb) print x
```

Вернуться к `add`:

```sh
(gdb) frame 0
```

Выбор кадра меняет контекст просмотра. Программа при этом не выполняется и не возвращается назад во времени.
### Прямая рекурсия

Рекурсия — это выполнение функции, при котором она снова вызывается до завершения предыдущего вызова.

При **прямой рекурсии функция вызывает саму себя**.

Пример — вычисление факториала.

```c
#include <stdio.h>

int factorial(int n)
{
    if (n <= 1) {
        return 1;
    }

    int result = n * factorial(n - 1);
    return result;
}

int main(void)
{
    int answer = factorial(4);
    printf("%d\n", answer);
    return 0;
}
```

В таком случае вывод bt будет:
```sh
#0  factorial (n=1) at recur.c:5
#1  0x0000555555555172 in factorial (n=2) at recur.c:9
#2  0x0000555555555172 in factorial (n=3) at recur.c:9
#3  0x0000555555555172 in factorial (n=4) at recur.c:9
#4  0x0000555555555196 in main () at recur.c:15
```

### Косвенная рекурсия
При косвенной рукерсии функция вызывает себя через другую

Рассмотрим на примере:
```c
void second(int n);

void first(int n)
{
    if (n <= 0) {
        return;
    }

    second(n - 1);
}

void second(int n)
{
    if (n <= 0) {
        return;
    }

    first(n - 1);
}

int main(void)
{
    first(3);
    return 0;
}
```

Тогда bt покажет:
```sh
#0  second (n=0) at recur.c:14
#1  0x000055555555514b in first (n=1) at recur.c:9
#2  0x0000555555555172 in second (n=2) at recur.c:18
#3  0x000055555555514b in first (n=3) at recur.c:9
#4  0x0000555555555189 in main () at recur.c:23
```

### Бесконеная рекурсия
Бесконечная рекурсия возникает, когда рекурсивные вызовы не достигают условия завершения.

Она может быть как прямой, так и косвенной.

Допустим в программе:
```c
int countdown(int n)
{
    if (n <= 0) {
        return 0;
    }

    int result = countdown(n);
    return result + 1;
}

int main(void)
{
    return countdown(3);
}
```

Тогда она будет выглядеть как:

## Изменение переменных: set var

`set var` позволяет изменить переменную во время отладки:

```sh
(gdb) set var x = 20
(gdb) print x
$4 = 20
```

Можно использовать выражения:

```sh
(gdb) set var x = x + 1
```

Так можно проверить, как программа поведёт себя с другими данными.

## Работа с массивами

```c
int numbers[] = {10, 20, 30, 40, 50};
```

Вывести весь массив:

```sh
(gdb) print numbers
$5 = {10, 20, 30, 40, 50}
```

Вывести один элемент:

```sh
(gdb) print numbers[2]
$6 = 30
```

Изменить элемент:

```sh
(gdb) set var numbers[2] = 100
```
### Вывод части массива

Оператор `@` позволяет вывести несколько последовательных элементов:

```sh
(gdb) print numbers[0]@3
```

Команда покажет три элемента, начиная с нулевого.

```sh
(gdb) print numbers[1]@3
```

Покажет три элемента, начиная с первого. Число после `@` — количество элементов.
### Настройки вывода

```sh
(gdb) set print array on
```

Включает вывод элементов массива по строкам.

```sh
(gdb) set print array-indexes on
```

Добавляет индексы элементов.

```sh
(gdb) set print elements 100
```

Устанавливает предел количества выводимых элементов.

```sh
(gdb) set print elements 0
```

Снимает это ограничение.
## Наблюдение за изменениями: watch

Команда `watch` останавливает программу, когда значение выражения изменяется:

```sh
(gdb) watch total
(gdb) continue
```

Например, при изменении total с 10 на 20 GDB покажет:

```sh
Old value = 10
New value = 20
```

* `watch` - при изменении
* `rwatch` - при чтении
* `awatch` - при чтении или записи
## Просмотр исходного кода

Команда `list`, или `l`, показывает строки исходника:

```sh
(gdb) list
```

Для отображения кода вместе с командной строкой можно включить текстовый интерфейс:

```sh
(gdb) layout src
```

Обновить изображение, если оно испортилось:

```sh
(gdb) refresh
```

Выключить этот режим:

```sh
(gdb) tui disable
```

Этот интерфейс должен поддерживаться сборкой GDB и терминалом.
