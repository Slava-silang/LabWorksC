# Отчёт по лабораторной работе «Численное решение нелинейных уравнений»

Выполнил: Балеев Станислав Евгеньевич. Группа М8О-101БВ-26.

**Тема:** решение нелинейных уравнений методами итераций, Ньютона и половинного деления.

**Цель:** изучить численные методы поиска корня, реализовать их на языке Си и сравнить результаты и число шагов.

**Задание:** составить процедуры решения нелинейных уравнений тремя методами. Уравнения передавать как параметры-функции. Для каждой пары метод/уравнение получить значение корня, сравнить его с табличным, определить показатель точности и число итераций. Если метод не удаётся применить, объяснить причину.

Рассматриваем следующие уравнения:

| №   | Уравнение           | Исходный отрезок | Табличный корень |     |
| --- | ------------------- | ---------------- | ---------------- | --- |
| 1   | 3x-14+e^x-e^(-x)=0  | [1;3]            | 2.0692           |     |
| 2   | sqrt(1-x)-tan x=0   | [0;1]            | 0.5768           |     |
| 3   | x+cos(x^(0.52)+2)=0 | [0.5;1]          | 0.9892           |     |


**Идея, метод, алгоритм:**

Создаём отдельные функции для каждого уравнения. Передаём их в процедуры поиска корня через указатели на функции. Благодаря этому алгоритм метода не зависит от конкретного уравнения.

Сначала проверяем границы отрезка и заданную точность. Если границы перепутаны, меняем их местами. Если функция равна нулю на одном из концов, возвращаем этот конец. При одинаковых ненулевых знаках на концах сообщаем об ошибке.

В методе половинного деления находим середину отрезка и вычисляем значение функции. Затем оставляем ту половину, на концах которой сохраняются разные знаки. Повторяем действия, пока половина длины оставшегося отрезка не станет меньше epsilon. Возвращаем его середину.

Для метода итераций преобразуем уравнение к виду x=f(x), отдельно ищем именно ту функцию, которая удвалетворяет условиям сходимости. Начинаем с середины отрезка и последовательно вычисляем.

В получаемых точках численно проверяем условие. По условию завершаем вычисления, когда:

x(k) - x(k-1) < epsilon

В методе Ньютона используем формулу:

x(k+1) = x(k) - F(x)/F'(x)

Начальное приближение также выбираем в середине отрезка. Перед шагом проверяем конечность производных и условие.

В текущей реализации останавливаемся по разности соседних приближений. Если шаг выходит за отрезок, процедура Ньютона возвращает ошибку.

Каждая процедура возвращает корень, а через указатели передаёт число шагов и значение `error`. При ошибке возвращается `NAN`. Число шагов ограничено значением 1000.

**Выбор функций для метода итераций:**

Для первого уравнения выражаем (e^x) и берём логарифм:

phi(x) = ln(14 + e^(-x) - 3x) 

Для второго уравнения выражаем тангенс:

phi(x) = tg(sqrt(1 - x))

Для третьего уравнения переносим косинус:

phi(x) = -cos(x^0,52 + 2)

Все эти решения были выбраны методом проб и ошибок, исследуя производные и проводя тесты через программу.

**Сценарий выполнения работы:**

Изучаем формулы трёх методов и условия их применения. Создаём функции уравнений и отдельно записываем преобразования для метода итераций. Реализуем численное вычисление первой и второй производных.

Проверяем методы на исходных отрезках.

Исходные данные: три уравнения из таблицы, соответствующие границы, epsilon=1^(-5)

Ожидаемый результат: приближения к табличным корням. При невозможности продолжить вычисления ожидаем сообщение, объясняющее причину остановки.

**Выводы:**

1. Метод половинного деления позволяет оценивать погрешность через длину оставшегося отрезка. Он не требует производных, но в проведённых вычислениях использует больше шагов, чем метод Ньютона.
2. Существуют формулы для нахождения примерных значений производных. Это позволяет очень удобно производить рассчёты.
3. Для метода итераций важно правильно преобразовать уравнение. Одно и то же уравнение можно записать в разных видах x=f(x), но сходимость зависит от выбранной функции и её производной.
4. Начальная точка влияет на поведение Ньютона. Для третьего уравнения шаг из середины исходного отрезка вышел за его границу. После изменения конца отрезка метод нашёл корень за три шага. 
5. Число итераций не полностью определяет объём вычислений. Один шаг Ньютона требует вычисления производных. Сравнивая методы, нужно учитывать и число шагов, и действия внутри каждого шага.
6. Условие остановки и погрешность корня — разные понятия. В дихотомии размер отрезка даёт оценку ошибки, а в итерациях и Ньютоне программа использует разность приближений.
7. Метод бинарного поиска универсальный, а методы итераций и ньютона быстрее и для их применения трбуется строгое выполнение условий.
