## Программа 4.с:
Текст задания: вводится целое число. Напечатать его двоичные разряды в заданном диапазоне.

Я не совсем понял, что подразумевает "задданом диапазоне", поэтому позволил пользователю самому вводить с какого по какой бит он хочет видеть информацию.

### Структура программы:
* Принимает на вход само число
* Принимает на вход номер первого бита
* Принимает на вход номер последнего бита
* Выводит информацию о двоичных разрядах числа с первого по последний

### Так же в программе есть реализация исключений. Алогритм ввыводит ошибку в случае:
* Если введенный первый бит больше 31 или меньше 1
* Если введенный последний бит больше 32 или меньше 1
* Если введенный последний бит меньше введенного первого бита

## Программа 18.с
Текст задания: Реализовать сложение двух вещественных чисел с использованием двоичных поразрядных операций. Для сложения мантисс можно использовать вещественный тип.

Я посчитал, что в задании не будет смысла, если использовать сложение мантисс через вещественный тип, поэтому постарался сложить их через побитовые операции. Признаюсь, что во время выполнения прибегал к глобальной сети, чтобы подробнее узнать об алгоритмах и структуре С, а также операциях (таких как ^, ~). Но только в ознакомительных целях, чтобы исправить ошибки, возникшие в результате написания кода.

### Структура программы:
* Принимает два вещественных числа
* С помощью сдвигов вычисляет знак
* С помощью сдвигов вычисляет порядок
* С помощью сдвигов вычисляет мантиссу и дописывает слева единицу
* Преобразует мантиссу меньшего числа к порядку большего
* С помощью побитового сложения складывает мантиссы
* Приводит мантиссу к нормальному ввиду, чтобы 24 бит был еденицей, а все перед нулями
* Проверяет порядок на диапозон
* Записывает биты в виде беззнакового целого типа
* Печатает число преобразуя в вещественный
