**Отчёт по лабораторной работе: вычисление функции с помощью ряда Тейлора**

Выполнил: Балеев Станислав Евгеньевич. Группа М8О-101БВ-26.

**Тема:** вычисление значений функции ln(2+x).

**Цель:** научиться вычислять значения функции с помощью ряда Тейлора, определять машинное эпсилон и сравнивать полученные значения с результатами стандартной библиотечной функции.

**Задание:** составить программу на языке Си, которая выводит таблицу значений функции `ln(2+x)`, вычисленных по формуле Тейлора и с помощью функции `log()`. Отрезок `[a,b]` разбить на `n` равных частей. Вычисления проводить по экономной схеме с точностью e*k.

**Идея, метод, алгоритм**

Представляем функцию в виде:
```text
                n  
ln(2+x)= ln2 + SUM(-1)^(n-1)(x^n/n2^n)
              i = 1
```

Для вычислений выбираем отрезок внутри [-1;1]. В этой области модуль отношения соседних членов не превышает (1/2), поэтому ряд сходится.

Чтобы не вычислять каждую степень отдельно, получаем следующий член из предыдущего. 

После добавления очередного члена вычисляем следующий и оцениваем оставшуюся сумму:

`if (fabs(temp) / (1.0 - fabs(x / 2.0)) <= tolerance)`

Если эта оценка не превышает `tolerance`, завершаем суммирование. Дополнительно ограничиваем число итераций значением 100. Если точность за это время не достигнута, программа должна сообщает.

Аргументы таблицы вычисляем по формуле:

`x = a + (b - a) * ((double)i / n);`

Таким образом, таблица содержит (n+1) точку. 

**Сценарий выполнения работы**

Сначала записываем разложение функции и определяем область, в которой ряд будет достаточно быстро сходиться. Затем составляем функцию определения машинного эпсилон.

Пишем функцию вычисления ряда. В ней сохраняем текущую сумму, очередной член и количество добавленных слагаемых. 

Для каждой точки вычисляем значение по ряду и через `log(2.0 + x)`. В таблицу выводим аргумент, оба результата, модуль их разности и количество итераций.

**Тест 1. Значения функции и число строк**

Исходные данные: n=4, k=10.

|(x)|Ожидаемое значение, округлённое до 10 знаков|
|---|---|
|−1|0,0000000000|
|−0,5|0,4054651081|
|0|0,6931471806|
|0,5|0,9162907319|
|1|1,0986122887|

**Тест 2. Одно разбиение**

Исходные данные: n=1, k=10.

Ожидаемый результат: две строки значений — для (x=-1) и (x=1).

**Выводы**

1. Следующий член ряда можно вычислять через предыдущий. Это позволяет обойтись без отдельного вычисления степеней и выполнять постоянное количество операций на каждой итерации.
2. Машинное эпсилон характеризует точность представления чисел выбранного типа около единицы. Уменьшение допустимого остатка ряда не устраняет ошибки округления, возникающие при вычислениях.
3. Один небольшой член ещё не означает, что вся оставшаяся сумма достаточно мала. Оценка через геометрическую прогрессию позволяет учесть все пропущенные слагаемые и сформулировать условие остановки.
4. Скорость сходимости зависит от аргумента. В выбранной области члены уменьшаются по модулю как минимум вдвое, поэтому для достижения малой величины остатка требуется сравнительно небольшое число итераций.
5. Число частей разбиения и число точек таблицы различаются на единицу. Вычисление аргумента по его номеру позволяет получить нужное количество строк без накопления ошибки от многократного прибавления шага.
